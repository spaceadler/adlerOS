# Screenshots

The docs show these images; each file name below is where it goes, in this
folder. Until one exists, its spot in the docs shows a broken image and an
HTML comment saying what belongs there.

**How to take them:** a desktop browser at 1440×900 or larger (or a phone, for
the `phone-` ones), the browser's own screenshot tool (Firefox: right-click →
*Take Screenshot*, Chrome: DevTools → ⌘⇧P → *Capture screenshot*). PNG. Use
the default aurora wallpaper unless the shot is about wallpapers, and blur or
crop anything private (addresses, names in notifications).
